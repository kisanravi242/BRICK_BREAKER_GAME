# 🕹️ Multi-Theme Python Brick Breaker Game

A feature-rich, dual-engine desktop arcade game built using **Python**, **Pygame**, and **Tkinter**, developed as an academic project (CA-2 for CSM 216).

---

## 🌟 Key Features
* **Dual-Engine Architecture:** Uses Tkinter for configuration menus and Pygame for smooth 120 FPS physics, rendering, and gameplay.
* **Multiple Themes:** Choose from **Space**, **Volcano**, and **Forest** visual themes.
* **Game Modes:** Classic mode and Boundary Breaker mode.
* **Difficulty Levels:** Easy, Normal, and Hard settings.
* **Procedural Audio:** Zero-dependency procedural WAV audio synthesis generated via Python's built-in `wave` and `struct` modules.

---
